## The line

> My grandma asked when I'm getting married, so I introduced her to my houseplant — she's already planning the wedding and the plant hasn't even agreed to the date.

One line, 162 characters. Family wedding pressure meets a houseplant: the turn is that grandma is already planning a wedding the "partner" never agreed to.

## How it works

`main.py` is deterministic: it writes the fixed line above to `/output/entry.txt` on every run — no randomness, no network, no environment input.

```sh
python3 main.py
cat /output/entry.txt
```
